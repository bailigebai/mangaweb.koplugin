# 内置阅读器灰度与全刷接入验证

日期：2026-10-08。源基线：`aa7698e3439a37c4cb600103039f3f7cc6c65925`（0.8.83）。

## 改动范围

新增 `mangaweb/graydither_bridge.lua`，从官方 PluginLoader 获取已启用的共享服务。正文窗口提供独立偏好存储、就绪判断、重绘和页面标识；灰度算法及全刷实现仍由 GrayDither 管理。正文 ImageWidget 才接入，封面及其他窗口不接入。

`mangaweb/settings.lua` 为本阅读器保存独立的五项 `graydither_*` 设置，灰度及自动全刷均默认关闭。共享存储复用原有保存、刷新和回滚流程；事务失败在新接口抛出错误，原 `save_reader_settings` 的返回约定保持不变。

`mangaweb/ui/webdav_reader_shell.lua` 传递真实正文窗口和页面、分片、滚动、显示模式标识。短暂加载保留已完成翻页累计；嵌入设置、独立设置窗口、休眠重建首屏基准；错误停止累计；关闭释放会话。`mangaweb/ui/koreader.lua` 提供“设置 → 灰度与全刷”入口。服务缺失、停用、不兼容或异常均保留原图片阅读。

## 可重复检查

在本仓库根目录运行（Python 需要 Lupa 2.8）：

```text
python spec/run_lua_specs.py
python spec/run_lua_specs.py --graydither-root ../gray
```

第一条运行 9 个本地规格；第二条另运行真实共享核心规格，共 10 个。本地 runner 固定使用自身父目录作为源码根，不引用原开发目录。共享核心路径也可由 `GRAYDITHER_ROOT` 提供；单独选择联测规格却未提供依赖时明确报错。

`graydither_contract_spec.lua` 使用真实 Session、真实 ImageWidget 和 BlitBuffer；仅图片解码、布局容器、时钟、窗口管理、设置保存使用可控本地替身。共享测试依赖的固定 KOReader 源码按其 `tests/fixtures/provenance.json` 校验 SHA-256；测试不执行网站请求、登录或授权。

## 实际结果

- 本仓库 10 个规格通过，78 个 Lua 文件语法通过。
- 额外使用原开发源的其余 30 个纯本地规格验证本工作树模块，合计 40 个规格通过。该批材料保存在本工作树外，不进入此次提交或安装包。
- 两个新增规格覆盖独立默认关闭及全局设置隔离、保存回滚、真实正文窗口所有权、分片/滚动标识、缺失/异常/关闭服务降级、嵌入及独立设置覆盖、加载/错误/休眠/尺寸变化/关闭。
- 真实像素输入 `8, 9, 128, 246` 关闭时原样输出，开启后为 `0, 17, 136, 238`；原图片缓冲不变。更新模型本身不计数，真实成功 paint 才累计；重复 paint 不重复累计；加载后继续累计。
- 真实全刷覆盖原生刷新与黑白闪烁；设置覆盖或正文关闭会取消待执行回调及黑层，迟到任务不会完成刷新。
- 先写失败规格再实现：缺少默认设置/会话/菜单、服务返回拒绝未降级、独立设置窗口未暂停，均从 RED 到 GREEN。真实共享保存失败规格发现新适配器仅返回 false 会漏报；改为失败抛出错误后通过，持久值与当前开关均保持原值。

## 验收与边界

设备同时安装并启用 GrayDither 0.3.0 和本版。在已授权漫画正文中打开“设置 → 灰度与全刷”，分别启用灰度、启用自动全刷并设为每两屏；连续翻页，打开设置、加载下一页、退出后重新阅读，检查只在正文按设置刷新。关闭两个开关或停用 GrayDither 后仍可正常阅读。

本次未安装到 Kindle，也未访问真实漫画、执行授权或发布。硬件刷新时序、真实触摸与最终画质仍需设备验收。现有源阅读器的分片与滚动显示行为不在本次修改范围。
