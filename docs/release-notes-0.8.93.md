# v0.8.93：章节切换、续读与全局缓存（2026-10-14）

## 改动

- 阅读设置直接上一话/下一话；任意章节保存章节、标题和页码，重开详情恢复对应章节。旧无章节记录只归默认章节，章节已移除时回到默认且不借用旧页码。
- 切章只允许一个请求，新章首图下载、解码并显示成功后才提交；失败或超时保留原章节；退出取消请求，迟到回调不重开阅读。图片列表请求也在退出时取消。
- 我的页面新增全局缓存策略与统计，正文/封面/列表共用256/192 MB默认额度、10分钟检查间隔。超过上限清到下限，优先最久未使用文件。使用中、预加载和收藏封面受保护；保护内容无法清除时明确提示。
- 清理分批执行，每项删除前再次检查访问、保护标记和文件身份；关闭插件取消任务。三字段同一输入弹窗，保存失败保留原策略。设置使用同目录临时文件，校验写入内容后原子替换，避免LuaSettings忽略写入失败。
- Zero登录不再提前清旧Cookie，临时会话验证通过后才提交。取消、失败及持久化失败保留旧会话。
- HTML和图片请求共用有界联网等待入口，使用KOReader现有连接接口，不在界面线程做同步DNS探测。区分DNS、超时、TLS错误。
