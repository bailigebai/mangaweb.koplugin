# v0.8.98：切章后重开续读修复

## 修复内容

阅读中切到新章节时，Reader已经在首图成功显示后保存章节和页码，但原详情控制器仍保留旧选择。关闭阅读并从原详情再次开始，会重新打开旧章节，并将刚保存的新历史覆盖。

本版在图片成功显示、历史写入成功后，通过可选回调同步原详情的章节选择、历史快照和续读页码。支持切到其他话再返回原章节/原页的往返操作；首图失败不推进状态，手动选择可保留并重试。不增加网络请求，不修改数据库结构、图片下载、授权或原WebDAVManga。

新章首图成功显示后即可记录，不要求额外翻页或先退出阅读；点击下一话但首图还没成功显示，或切章失败，仍保留旧章。
