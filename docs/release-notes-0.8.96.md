# v0.8.96：修复安卓授权 HTTPS 证书路径

授权模块此前到安卓外部用户数据目录寻找证书，该目录不含 KOReader 打包的 CA，导致激活请求发出前就返回“HTTPS 组件不可用”。改用 KOReader 程序目录中的 `data/ca-bundle.crt`。

保留自定义证书注入、HTTPS 证书链与域名校验、固定激活地址、超时与响应限制。授权签名、设备身份和绑定逻辑未改变。不需要清空账号或本地授权文件。

回归测试先复现原版 tls_unavailable，再验证修复后能完成请求；同时覆盖自定义 CA、缺少 CA、错误服务器域名与不可信证书。测试仅使用合成数据，不提交真实激活请求。

0.8.95的Zero安卓登录与插件重开保留已获用户确认。本版实际授权激活仍需安装后设备验收；Bilibili正文仍未接通。原WebDAVManga未因本次授权修复再作修改。
