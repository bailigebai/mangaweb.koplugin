# v0.8.94：设备旋转交付（2026-10-14）

## 实现

用户确认沿用WebDAVManga原版手动四方向，退出阅读保留方向。阅读设置 → 设备旋转 → 0/90/180/270度；保留当前章节和页码。同方向不重复处理，准备失败恢复原设备方向和旧页。只修改MangaWeb，原WebDAVManga及KOReader库未改。

旋转使用KOReader公开SetRotationMode事件；当前页按新视口从已拥有的本地原图准备，成功后才替换原生窗口、手势和灰度会话。分格安全恢复整页后按原格序重新进入；返回详情/书架时按实时方向重建根窗口、绘制边界和触摸范围。
