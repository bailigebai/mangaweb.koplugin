# v0.8.95：修复 Zero 登录后的会话保存

设置写入时关闭重复的 Lua 文件包装，修复已验证账号无法保存 Cookie 的问题。现场已读到“账号验证成功，保存失败”的定向记录；此前该缺陷同样会影响阅读参数和缓存策略保存。

保留已有会话隔离、验证成功才提交、保存失败回滚与原子替换。未验证提示改为“无法确认登录状态，请重试”，不再声称会话已保存。售价提示50元保留，Bilibili正文仍未接通。

## 验证与安装

源码及安装包解包代码76组Lua规格、89项语法检查通过，9项Python检查通过。真实KOReader写入函数对照：旧版失败、修复后会话可重读；独立审查覆盖既有文件替换、替换失败回滚。

升级后彻底重启KOReader，登录Zero，关闭插件再打开，确认仍为登录状态；再彻底重启KOReader，检查会话与阅读参数是否保留。电脑检查和安装回读不能替代此项实机验收。
