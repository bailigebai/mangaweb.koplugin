# MangaWeb 0.8.84 设备测试版

此前灰度插件只处理普通文档，MangaWeb 内置漫画阅读器没有接入。0.8.84 将正文图片接入 GrayDither 的共享服务，提供灰度抖动和独立全刷设置；同时修复已有阅读设置升级后新增关闭默认值丢失、导致设置保存失败的问题。

## 使用

- 同时安装并启用 `graydither.koplugin` 0.3.0。
- 在漫画正文打开“设置 → 灰度与全刷”，分别开启灰度抖动、自动全刷。两个开关独立保存，均默认关闭；普通文档及其他内置阅读器的设置不影响这里。
- 可选择全刷间隔、原生全刷或黑白闪烁，以及黑屏停留时间。按实际成功显示的新屏累计，重复重绘不计数；短暂加载保留累计，设置覆盖、休眠及退出取消待执行刷新。
- 灰度在正文最终缩放后软件模拟16级灰阶，不能升级为硬件256级灰阶。封面、详情预览及原图缓存不应用此处理。
- 缺少、停用或共享服务异常时仍按原方式阅读。原有阅读授权流程不变，开始阅读仍需有效授权。

## 安装或更新

下载本页的 `mangaweb-0.8.84.zip` 并解压。退出 KOReader，先备份原插件文件夹，再将 `mangaweb.koplugin` 放入设备的 `koreader/plugins/`；更新时保留原缓存和 KOReader 设置目录。GrayDither 0.3.0 同样放入该目录并启用，重启 KOReader。

正确路径为 `koreader/plugins/mangaweb.koplugin/main.lua` 和 `koreader/plugins/graydither.koplugin/main.lua`，不要多套一层文件夹。
