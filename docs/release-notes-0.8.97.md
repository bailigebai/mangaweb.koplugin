# v0.8.97：安卓授权签名校验兼容修复

安卓现场自检确认：KOReader合并加密库能加载，但没有向插件公开RSA验签所需的BIO、PEM、RSA及EVP函数。之前插件将该能力缺失统一返回false，界面误报“授权签名无效”。0.8.96的HTTPS证书修复保留。

先检查全部原生验签入口；完整时继续使用原生库，缺少时使用限定当前产品格式的独立RSA-2048/e=65537/SHA256/PKCS1-v1.5公钥验签。沿用KOReader的SHA256，不增加原生库、不更换应用，不改服务器、公钥、签名协议或设备绑定。

严格检查SPKI公钥格式、规范Base64、签名小于模数以及完整PKCS1填充和SHA256 DigestInfo。只缓存一把公开公钥参数，计算长度与循环有固定上限；不实现私钥、签名或密钥生成。

独立OpenSSL公开向量覆盖合法、篡改、错误公钥、错误填充与哈希算法、异常编码和非规范签名。额外以6把独立公钥对照Python大整数参考，96份合法签名及96份篡改消息全部符合预期；真实Kindle ARM运行库的原生、独立验签和隐藏原生入口三路径40项检查通过。手机实际密钥激活与重开保留仍需实机确认。

覆盖程序文件后彻底重启KOReader，再使用原密钥激活。保留账号设置、收藏数据库及settings/mangaweb-license.json，避免改变本机授权身份。临时诊断不进入安装包，原WebDAVManga未改动。Bilibili正文仍未接通。
